# changelog

Completed work, grouped by release. Open work lives in [GitHub Issues](https://github.com/mavericksxx/pokemon-harness/issues) (see [BACKLOG.md](BACKLOG.md) for how they are organised).

## Unreleased

- **a Codex session's speech bubble could show a bare digit instead of the command it ran** (e.g. `$ running 3`) — Codex has no hook-backed status source, so its tool text is scraped from raw terminal bytes; a mid-redraw repaint could glue Codex's own status-footer counter directly onto a captured "Ran ..." line with nothing separating them, and when that leftover fragment started with a bare digit, the digit became the whole "command." Hardened the scraping regex to reject a captured target whose first word is a bare number, plus a defensive fallback in the bubble-label formatter for any numeric-only/too-short target that slips through another path. [#1](https://github.com/mavericksxx/pokemon-harness/issues/1). Claude Sonnet subagent, reviewed/merged by the orchestrator
- **a garden with only idle, roaming subagents never downshifted to the low-power heartbeat** — the dirty-flag rendering pass that lets an idle garden paint at 1fps instead of 60 checked "does any subagent battle exist at all," which stayed true for a subagent that was merely wandering, not actually animating anything new. Narrowed to only mark the garden dirty while something is genuinely mid-wave (approach/faceoff/attack/mega) or mid-poof — a settled roaming/retired subagent's own idle-loop animation was already self-marking dirty through the same mechanism a stationary walker uses, so nothing stopped rendering, only the redundant always-on flag did. [#7](https://github.com/mavericksxx/pokemon-harness/issues/7). Claude Sonnet subagent (advisor-reviewed — confirmed no coverage gap across the full lifecycle), reviewed/merged by the orchestrator
- **an advisor companion (or an ordinary subagent's pokemon) could get recalled/queued while its own real task was still running** — every subagent completion, advisor or ordinary, gets broadcast to both the advisor and battle systems, on the assumption each silently ignores a task id it doesn't recognize. Neither actually did: an unrecognized id fell back to "recall/queue the oldest live one for this parent" instead, so one dispatch finishing could incorrectly recall an unrelated, still-running advisor companion (confirmed live) or queue an unrelated roaming subagent into a battle early. Both managers now track which task ids they've confirmed belong to someone else and no-op on them immediately, and their fallback only ever considers a companion/battler that was genuinely never stamped — never one already identified as something else. Claude Sonnet subagent (architecture advisor-reviewed beforehand — the fix and its full two-file blast radius were both its finding, not just mine), reviewed/merged by the orchestrator
- **the advisor subagent's model, and a `poke-delegate` dispatch's model, are now settings instead of fixed at whatever the calling session happened to use** — new "advisor model" picker (harness home settings: Fable 5.1 / Opus / Sonnet / Haiku / custom, defaulting to Fable) and an optional free-text "codex delegate model" override, blank by default since Codex already tracks its own configured flagship with nothing set. Claude's `fable`/`opus`/`sonnet`/`haiku` are genuine portable aliases (`claude --help` documents them resolving to "the latest model" in each tier), so the picker keeps tracking new releases with no app update needed; confirmed live that an unavailable choice fails cleanly at the moment the advisor is actually consulted, never at session startup. Claude Sonnet subagent (own advisor consult caught a missing `.trim()` on both new settings before landing), reviewed/merged by the orchestrator

## v1.14.0 — 2026-09-04

- **your own pokemon now faces you during a completion battle, mega evolution included** — it used to stand at the bottom-left of the pair showing its BACK sprite (mirroring mainline Pokémon games' "your own party shows its back" convention), which meant a mega evolution reveal — something that only ever happens to your own pokemon — played out facing away from the camera. Flipped which corner shows which sheet, with zero new mirroring math: the parent now shows its native, unmirrored FRONT sheet, and the challenger shows its BACK sheet where the species has one (falling back to a mirrored front sheet where it doesn't, so it still faces roughly the right way). Claude Sonnet subagent (architecture advisor-reviewed beforehand, and again by the implementer before reporting done — caught two real teardown-path gaps where a delegate's or a retired battler's walker could get stuck facing away from the camera forever), reviewed/merged by the orchestrator

## v1.13.0 — 2026-09-04

- **`poke-delegate` pokemon now fight completion battles like any other subagent** — previously a deliberate limitation: a delegate is a full independent session with its own walker, not a `BattleManager`-tracked battler, so it could never queue for a fight or trigger its parent's mega evolution. A new `Challenger` interface abstracts the narrow surface the battle system actually needs (position, stance, bubble, attack/move display) and a `WalkerChallenger` adapter forwards it to the delegate's existing live walker without the battle system taking ownership of it; a finished delegate now queues through the same global one-battle-at-a-time lock as any other subagent, and its walker is handed back untouched (bubble cleared, position resynced) the moment the battle concludes or is torn down early. Claude Opus subagent (architecture advisor-reviewed beforehand, given the shared-lock invariant at stake), reviewed/merged by the orchestrator
- **pick alternate battle forms right in the picker** — Zacian's Crowned Sword form, Calyrex's Ice/Shadow Rider forms, Giratina's Origin form, and 130+ others now show a form sub-panel (both at session creation and via "change pokemon") instead of being unreachable. 134 forms generated from Showdown's own data, sprite-availability-verified against its CDN; a session created directly on a form now hatches as that exact form instead of silently normalizing back to the base species. Claude Sonnet subagent, reviewed/merged by the orchestrator
- **mega evolution now covers the full classic roster, not just the species gen5ani happened to animate** — Charizard's Mega Y, Venusaur, Blastoise, Gengar, Diancie, and 19 others were previously excluded because Showdown's animated BW sprite set has no art for them; they now fall back to the same static Smogon art gen6-9 species already use. Table grew from 23 to 46 species (24 to 48 forms) — every real, official pre-Legends-Z-A Mega Evolution. GPT-5.6 Luna delegate, reviewed/merged by the orchestrator
- **night-mode trees no longer split into a bright canopy over a dull trunk**: v1.12.0's environment wash lives below the walker layer (so it can darken tiles without also crushing character color), but tree canopy and structure roofs are deliberately parented at or above that layer for correct Y-sort occlusion against walkers — leaving them out of reach of the wash and only ever getting the weak character-tier dimming, while their own trunks got the full treatment. Canopy and roof sprites now receive an equivalent per-sprite tint, sampled from the same gradient the wash itself uses, so every part of a tree lands at the same night darkness. Claude Sonnet subagent, reviewed/merged by the orchestrator

## v1.12.0 — 2026-09-03

- **the orchestrator's delegation workflow now works out of the box on a fresh install, not just this developer's own machine**: every claude spawn now also bundles a read-only `investigator` subagent (same shadow-guard pattern as `advisor`), exposes the app's own `poke-delegate` Codex-delegate CLI to the session's own env as `POKEHARNESS_DELEGATE_CMD` (previously referenced by HARNESS.md's prose but not actually invocable — `command not found` on any install, including this one), and HARNESS.md's own instructions now spell out the full lane-routing procedure (Codex-first, Claude-sonnet fallback, never Codex→haiku) and the exact invocation, with a real command-injection hole in an early draft of that invocation caught and fixed by the implementing agent's own mandated advisor consult before it shipped. Claude Sonnet subagent, reviewed/merged by the orchestrator
- **hover tooltips no longer hang for ~490ms after the mouse leaves**: the shared `.tip` component's fade-out inherited the same 400ms debounce meant only for fade-in (so a tooltip doesn't flash on a quick mouse-pass), making it look stuck across every place it's used. Show and hide now have separate timing — hide is near-instant, show is unchanged. Claude Sonnet subagent, reviewed/merged by the orchestrator
- **advisor companions triggered by a dispatched subagent's own internal consult no longer orphan on screen for up to 15 minutes**: the correlation mechanism that despawns a companion deliberately excludes a subagent's own nested transcript activity (to keep it from polluting the top-level battle system) — but the spawn side had no matching exclusion, so a nested consult's companion could spawn with no path to ever receive a despawn signal. - **the advisor companion's own body sprite no longer overlaps its parent's tool-use speech bubble**: its offset was measured from the parent's *feet*, while the bubble is anchored off the parent's *head* — close enough that a tall companion sprite routinely reached into the bubble's box. The companion's vertical position is now derived each frame from the bubble's own known geometry, guaranteeing clearance regardless of species; a follow-up flipped the z-order tie-break so the bubble also wins against the companion's aura (larger than the body, and still able to reach the bubble) now that body-occlusion is no longer possible. Claude Sonnet subagent, then GPT-5.6 Luna delegate for the z-order follow-up, reviewed/merged by the orchestrator
- **night-mode pokemon no longer look washed-out and dull**: the single full-scene night wash multiplied every sprite's color by a fairly saturated navy blue (a Pikachu yellow rendered out as olive-brown), crushing every character's own hue the same way regardless of species. Split into a weak, desaturated tint that still dims characters without erasing their color, plus a separate full-strength wash confined to the environment (tiles, border ring) — landing close to the original night mood everywhere except on characters, which now stay legible. Claude Sonnet subagent, reviewed/merged by the orchestrator

## v1.11.0 — 2026-09-03

- **advisor consults work out of the box on a fresh install, with zero personal config**: every claude spawn now carries a bundled `advisor` subagent (via Claude Code's `--agents` flag) matching the one this feature was modeled on — same "advises only, never edits" contract, restricted to `Read`/`Grep`/`Glob`. Previously the hovering-companion feature (v1.10.0) only ever fired for someone who'd independently hand-written their own `~/.claude/agents/advisor.md`; a fresh install had none, so the feature was silently dormant. Skipped automatically if you already have your own `advisor.md` (user- or project-level) — never shadows a hand-tuned one. HARNESS.md's own template now tells the session to actually call it before architecture decisions and before reporting a deliverable done. Claude Sonnet subagent, reviewed/merged by the orchestrator
- **a stuck advisor companion can no longer linger forever**: the completion signal that despawns a companion pokemon occasionally never arrives (root cause not yet fully understood — suspected in the async-completion transcript-scraping mechanism for a long, continuously-busy session), leaving it hovering permanently until an app restart. Every companion now self-despawns after 15 minutes regardless, with a distinctly-logged diagnostic line so a recurrence is traceable. Claude Sonnet subagent, reviewed/merged by the orchestrator
- **roaming subagents no longer flash a raw tool/command bubble on every single tool call**: a subagent doing normal work made its speech bubble change almost constantly ("Read x.ts" → "$ npm test" → "Edit y.ts" …), which read as noise rather than information. The bubble now only ever shows the subagent's own one-line task description, on the same intermittent cadence as before — no live per-tool-call text. Claude Sonnet subagent, reviewed/merged by the orchestrator
- **the advisor companion no longer disappears behind its own session's tool-use speech bubble**: the bubble already carried a hardcoded always-on-top zIndex, which the companion (an ordinary Y-sorted value) could never beat. Both now share the same overlay tier, keyed off each sprite's own owner position, so the companion reliably wins against its own parent's bubble without unconditionally covering an unrelated session's. Codex luna delegate, reviewed/merged by the orchestrator
- **roaming subagents no longer pile up in one corner of the garden**: their roam-home pick always tried the single mathematically-farthest corner from their parent first, and only avoided tiles claimed by that *same* parent's own other subagents — so a busy session's battlers clustered together, and different sessions whose farthest corner happened to match could converge on each other too. Roam-home selection now shuffles among the top few far corners instead of always picking the same one, and avoids every currently-roaming battler garden-wide, not just siblings. Claude Sonnet subagent, reviewed/merged by the orchestrator
- **every topbar popover and dropdown works again** (usage limits, quick settings, the audio player, and the Arceus-summon/new-garden/delete-garden dialogs) — they'd started rendering behind the terminal panel and their outside-click areas had shrunk to the topbar's own height. Root cause: a CSS container query on the topbar (added for a handful of responsive breakpoints) was quietly creating both a new stacking context and a containing block for fixed-position elements. Converted to plain media queries and outside-click dismissal now follows the app's usual pointerdown pattern instead of a full-screen catcher div. Codex luna delegate, reviewed/merged by the orchestrator
- **completion battles last ~8.3 seconds instead of ~2**: the exchange used to be just one attack each, over almost as soon as it started. Now 8 attacks alternate between the parent and the subagent at a more deliberate pace, reading as a real back-and-forth instead of a blip. Codex luna delegate, reviewed/merged by the orchestrator
- **a subagent's speech bubble now reads as a subagent's at a glance**: smaller box, dashed border — mirroring the same solid-vs-dashed convention the roster cards already use to mark a transient battler apart from a live session. The main session's own bubble is unchanged. Claude Sonnet subagent, reviewed/merged by the orchestrator

## v1.9.0 — 2026-09-03

- **garden no longer loses its WebGL context (and "refreshes" or needs a rebuild) when many pokemon spawn at once**: sprite decoding allocated one 2D canvas per GIF frame and left them to garbage collection, and every disposed terminal WebGL context lingered because the xterm addon never calls `loseContext`; under a spawn burst Chrome evicted the oldest context, which is the garden's. Frames now composite straight into the sheet canvas (a 60-frame pokemon goes from 126 transient canvases to 6, two of which persist), at most two decodes run at a time, and disposed terminal contexts are released explicitly. The rebuild budget is 4 attempts per minute instead of 2, and the context-lost log row records the attempt and seconds since the previous loss. Claude Sonnet subagent, reviewed/merged by the orchestrator
- **Arceus is no longer claude-only, and the app has a first-run step**: his setup dialog has a provider picker (claude / codex; codex gets his persona typed after a short delay since the app wires no hooks into a top-level codex session, and `@@relay` stays claude-only for now — flagged inline). A welcome dialog on first launch picks the default provider (the same setting new agents use) and offers to summon Arceus; the app never auto-summons him before that choice is made, and an existing summon.json survives "not now". Existing installs see the welcome once. Claude Sonnet subagent, reviewed/merged by the orchestrator
- **Arceus's terminal drops to a shell when his CLI exits**, like every other session, instead of a dead pane you cannot type in; re-summoning from his chip replaces the shell. Same subagent
- **hooks.sock can no longer be clobbered by a second app instance** (bit twice on 2026-09-01/02): a second launch sharing the userData dir used to delete the live hook socket at startup and leave a dead file behind, after which every hook connect got ECONNREFUSED until a manual restart — no subagent battlers, no tool bubbles, `poke-delegate` spawns failing. Now the app takes a single-instance lock (the second launch exits at once and the running window comes to the front); hookBridge remembers its socket's inode and re-checks it every 5s and before every spawn, re-binding and showing one toast if the path was replaced; and shutdown only removes the socket if it is still ours. Battlers now have the same explicit hit box, and a capture-phase resolver on the character layer re-tests every visible walker/battler against the point and hands the click to the one whose feet are nearest (hidden-workspace pokemon and charm hotspots excluded). Every battler click now writes a `battle` diagnostics row (key, parent, species). Claude Sonnet subagent, reviewed/merged by the orchestrator

Settings → harness home: "load HARNESS.md into every session" toggle (default on), path, open-file button. Edits apply to the next session start. Claude Sonnet subagent, reviewed/merged by the orchestrator
- **finished subagent pokemon no longer look translucent**: the "off duty" cue for retired battlers was 75% opacity, which read as ghosting at garden zoom (the map showed through). It is now an opaque hue-neutral darkening tint, applied on retire and on restore, cleared on revive; the evolution ceremony also restores sprite alpha on its teardown path. Codex gpt-5.6-luna delegate, reviewed/merged by the orchestrator
- **+ terminal moved into the drawer tab strip**: the new-terminal icon no longer sits in the topbar beside "+ new garden"; it is the trailing item of the terminal drawer's session tabs (garden view) and, in terminal view, sits beside "+ add agent" in the focus sidebar's action row. Codex gpt-5.6-luna delegate, reviewed/merged by the orchestrator

## v1.8.0 — 2026-09-01

Backlog sweep + phase F performance pass — seven items delegated to Claude Sonnet subagents in isolated worktrees, reviewed/verified/merged by the orchestrator.

- **mega evolution during battles (phase D)**: the main agent's pokemon mega-evolves for the duration of a completion battle when its species has a mega form in Showdown's gen5ani sprite set, then reverts. Coverage is the 23 species gen5ani actually has (each id curl-verified: charizard-megax, mewtwo X/Y, alakazam, ampharos, scizor, tyranitar, blaziken, gardevoir, mawile, medicham, manectric, banette, absol, garchomp, lucario, abomasnow, beedrill, steelix, glalie, salamence, latias, latios, rayquaza — the other ~23 real megas only exist in Showdown's Gen-6+ `ani` set, a different base URL, and were left out). X/Y is picked deterministically per battle. The sheet is prefetched the moment the battle is admitted so it lands before the faceoff; the swap is a half-second white flash beat (instant under reduced motion) with a "«Label» Mega Evolved!" float; the revert runs at every battle-end and teardown site (conclude, force-conclude, ending, end-all, hard teardown/dispose). A load that arrives after the fight moved on is discarded; an evolution ceremony or manual species swap supersedes the temporary form cleanly. Fourteen of the 23 forms have no back sheet and use the existing front-sheet fallback during the fight
- **dirty-flag garden rendering (phase F, second slice)**: the garden now paints only when something visibly changed instead of 60 identical frames a second. Pixi's automatic render pass is removed for good; the game-logic tick calls `app.render()` when a frame is dirty — sprite frame advances (via `AnimatedSprite.onFrameChange`, which also fires on sheet swaps), walker/battler transforms, badges/labels/zzz/floating text, tool bubbles, camera movement (`Camera.update` now reports whether it moved), any active battle/fx/evolution ceremony/closing ritual, night-time lamp sway (gated on night weight so a daytime garden isn't pinned at 60fps), pond water frames, reconcile/resize — or when the 1s heartbeat is due, which bounds any missed source to a second of staleness. `gardenCharm`'s visibility-blind rAF pulse is folded into the ticker and gated on the render pause. A `renderedFrames` diagnostics counter sits next to `rendererTicks` so the idle ratio is verifiable from logs. Known coarse spot: any live subagent battler counts as "battle active" and keeps full-rate rendering while present
- **main pollers back off when idle (phase F)**: `costWatcher` (5s), `taskNotificationWatcher` (2s), and `arceusRelay` (2s) used to tick forever; each now keys off the `sessions:checkpoint` status mirror — cost only while a tracked session is working, task notifications while a parent is working or has async agents outstanding, the relay while arceus is working or has queued relays — polling immediately on resume and once more before pausing so nothing is delayed past the old cadence
- **"low-res garden (experiment)"** toggle in settings → diagnostics (default off): renders the Pixi canvas at 1× with `image-rendering: pixelated` for an A/B on retina GPU cost; labels get softer; applies on next restart
- **idle-energy pass (phase F, first slice)**: the garden stayed mounted and rendering at full tilt in every view mode — including terminal mode and while the window was minimized or hidden. Pixi's own render pass is now removed from the ticker (and `Ticker.shared`, which drives sprite frame-stepping independently of the app ticker, is stopped) whenever the page is hidden, the window is hidden/minimized (main forwards `hide`/`show`/`minimize`/`restore`, covering Cmd+H where `document.hidden` doesn't flip), or the view is terminal-only; the game-logic tick keeps running so work accumulators and battle timeouts keep wall-clock semantics. Both tickers are capped at 60fps (ProMotion was pushing 120Hz for pixel art). The 14 `setInterval` sites were audited and found already gated or cheap. `backgroundThrottling: false` stays (the PTY parsers need it)
- **orphaned focus-mode composer removed**: `FocusComposer.tsx`, `pty/focusQueue.ts`, its boot call, and its CSS (297 lines) were dead since the parity sweep dropped their only mount site; Arceus's relay path (`injectionQueue`, `writePty`, bracketed-paste wrapper) is untouched
- **ResizeObserver storm — closed by investigation, no code change**: every named suspect already carries a targeted fix from earlier commits (fixed-height roster cards, splitter-drag guards on both terminal fit and canvas sync, absolute/`max-content` measurement copy in the overflow chip row, and the per-message log dedupe); harness.log shows every sustained burst predates those fixes, with only scattered 1-row residue since, consistent with ordinary OS window resizes
